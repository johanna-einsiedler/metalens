A reproduction agent will be asked to re-derive a specific number by running an
economics paper's own code. That number has been blinded out of the table it
came from. Your job is to decide whether the text below hands the agent that
number anyway, letting it answer without running anything.

Each CASE below is one flagged match. Decide each independently.

Decide between:

  "remove"  — the text states this number AS the quantity the agent is meant to
              reproduce, or as something arithmetically equivalent to it. The
              agent could copy it. Example: "Mean = 7.748" where 7.748 is the
              blinded mean; "the 0.147 estimate is a 118 percent increase" where
              0.147 is the blinded coefficient.

  "keep"    — the number appears for an unrelated reason and merely happens to
              equal the blinded value. Examples: a treatment probability
              ("p = 0.25"), a hypothesised null a test compares against ("test
              of equality with 0.10"), a sample size, a year, a threshold, a
              different quantity entirely.

Judge only the occurrence shown, in the text shown. When the two readings are
genuinely balanced, choose "remove": wrongly keeping a leak silently corrupts a
result, while wrongly removing one only costs a regression.
